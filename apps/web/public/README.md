# AlmostHack Static Assets Directory

Place static assets here for Next.js:
- `assets/almosthack/brand/` — Logos, wordmarks, icons
- `assets/almosthack/scribbles/` — Hand-drawn SVG scribbles & decorative marks
- `assets/almosthack/illustrations/` — Editorial illustrations (AVIF/WebP/SVG)

Files placed in `public/` are served at the root URL (e.g. `public/assets/...` -> `/assets/...`).
